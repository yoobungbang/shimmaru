# JUDGE_APPEAL — 심사 어필 포인트 초안

> 2026 관광데이터 활용 공모전(웹·앱 개발 부문) 심사위원 대상 어필 포인트 초안.
> README.md와 shimmaru.md 내용을 근거로 작성. 발표/PPT 제작 시 갱신.

## 1. 지역특화성
- 경상북도 22개 시군 — 전통문화 자원 밀도는 전국 최고 수준이나 방문은 안동·경주 등 일부 도시에 편중.
- 쉼마루는 **데이터로 숨은 시군을 발굴·추천**하는 것을 핵심 가치로 설계. 봉화·영양·청송 등 한적한 내륙 지역도 코스 추천 대상에 정식 포함.
- 코스 생성 엔진에 "숨은지역 보너스"를 명시적 스코어링 요소로 반영(데이터랩 실방문자 데이터 기반) → 단순 인기순 추천이 아닌 **분산 유도형 추천**.

## 2. 공공데이터(한국관광공사 OpenAPI) 활용의 깊이
단순 목록 조회에 그치지 않고 여러 서비스를 조합·재가공:

| 서비스 | 활용 방식 |
|--------|----------|
| KorService2 (관광정보) | 장소·검색·주변·상세·갤러리, 4개 언어 자동 전환 |
| KorWithService2 (무장애) | 휠체어·유모차 등 접근성 코스 구성 |
| KorPetTourService (반려동물) | 반려동물 동반 가능 장소로 코스 구성 |
| TarRlteService (연관추천 빅데이터) | "함께 찾은 곳" — 실제 동반 방문 패턴 기반 추천 |
| DataLabService (데이터랩 빅데이터) | 시군별 방문자 통계 대시보드(`/insights`), 코스 엔진의 숨은지역 보너스 산출 근거 |
| 행안부 문화축제 표준데이터 | 진행/예정/종료 축제 캘린더, 코스와 연계 |

→ **"여러 공공 API를 하나의 추천 알고리즘으로 재구성했다"**는 점이 단순 지도 앱과의 차별점.

## 2-1. 데이터 신뢰성 원칙
- 미신청/미승인 API(빅데이터·무장애·반려동물 등)는 **가짜 데이터로 채우지 않고** "활용신청 안내" 상태로 명시적 폴백.
- 기상청 단기예보 미신청 시에도 평년값으로 graceful 폴백 — 항상 실제 데이터 또는 명시된 대체값만 노출.
- 이는 공모전 실사용 심사 시 "데이터 정합성"에서 감점 요인을 사전 차단하는 설계.

## 3. 기술적 완성도
- 코스 자동 생성 알고리즘: 카테고리 가중치 × 거점 반경 × 숨은지역 보너스 × 동반자 가중치 × 강수 경향(기상청) → 2-opt 동선 최적화. 단순 랜덤/거리순이 아닌 **다변량 스코어링 + 경로 최적화**.
- 축제 연계: 거점 지역·여행 기간과 실제 겹치는 축제만 코스에 연결(무관한 축제 노출 방지).
- 다국어(한/영/일/중) + PWA(오프라인 폴백, 홈 화면 추가) — 외국인 관광객 접근성까지 고려.
- API 키 미노출 설계(Vercel Edge Function 프록시) — 보안 기본기.

## 4. UX 차별점
- 챗봇형 인터페이스로 진입장벽을 낮춤(지역·기간·동반자·취향만 답하면 완성된 코스 제공).
- "경북 데이터 인사이트"(`/insights`) — 방문자 통계를 사용자에게 직접 시각화해 데이터 활용의 투명성을 강조.
- "쉼마루 Wrapped"(`/report`) — 개인 여행 기록을 연말결산 스토리 형태로 제공, 재방문/공유 유도.

## 5. 확장 가능성 (심사 시 언급용)
- 현재 MVP는 프론트 단독 + Vercel Edge Function 구조로 빠른 배포·검증에 최적화.
- 2차 단계로 서버(백엔드) + DB 도입 시 사용자 코스 저장, 공유 링크 영속화, 관리자 통계 고도화가 가능하도록 localStorage 스키마를 DB 친화적으로 설계.

## 6. 잠재 약점 및 대응 논리 (자체 점검용)
| 예상 지적 | 대응 논리 |
|-----------|-----------|
| 서버/DB 없이 localStorage만 사용 — 데이터 영속성 우려 | MVP 단계 의도적 선택. 필드명을 DB 친화적으로 설계해 마이그레이션 용이. 공모전 심사 시연에는 충분. |
| 빅데이터/무장애/반려동물 API 미승인 시 기능 제한 | 승인 즉시 활성화되는 구조이며, 미승인 상태에서도 가짜 데이터 없이 명확히 안내 — 오히려 데이터 진정성 어필 포인트로 전환 가능. |
| 백엔드(Java) 부재 | 최초 기획(`shimmaru.md`)은 2차 단계 항목으로 명시. MVP 심사 범위에서는 필수 아님. |
