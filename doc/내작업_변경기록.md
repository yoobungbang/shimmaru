## 2026-09-20 — 큐레이션 코스 배지 다국어화 ❌ **폐기 (소현님 작업과 중복)**

**문제**: 한국어 모드인데 추천 코스 카드 배지가 `ANDONG · 2N3D` 로 영문 표기됐다.

**내가 한 것** (`a27aca1`, 현재 `backup/badge-fix-20260920` 에만 있음): `lib/courseBadge.ts` 를 만들어 시군구명 + `duration.*` i18n 키를 조립하도록 바꾸고, 렌더 4곳과 죽은 `badge` 필드를 정리했다.

**폐기 사유**: 같은 날 소현님이 `fac338e` 에서 **동일한 문제를 독립적으로 해결**했다. `lib/curatedLabel.ts` 로 `curatedCourseLabel()` / `curatedRegionLabel()` / `curatedDurationLabel()` 을 만들었고, 커밋 주석까지 같은 맥락이다.

> *"예전엔 `badge: 'POHANG + YEONGDEOK · 1N2D'` 영문 문자열을 데이터에 직접 박았는데, sigunguCodes/duration 이 이미 있으므로 여기서 파생시켜 4개 언어를 모두 커버한다."*

**소현 버전이 더 나은 점**:
- `shortName()` 으로 행정 접미(시·군 / 市·郡)를 떼어 `포항 · 영덕 · 1박 2일` 처럼 짧게 만든다. 내 버전은 `포항시 · 영덕군` 이 그대로 나왔다.
- `DURATION_KEY` 를 `Record<TripDuration, string>` 으로 둬서 `TripDuration` 에 값이 추가되면 타입 에러로 잡힌다. 내 삼항 연산자 방식은 조용히 통과한다.
- 지역/기간 라벨을 따로 쓸 수 있게 함수를 쪼개놨다.

**조치**: rebase 시도 → 3파일 충돌 → `rebase --abort` 후 `main` 을 `staymaru/main` 으로 리셋. 내 커밋은 `backup/badge-fix-20260920` 에 보존. **되살릴 필요 없다.**

**교훈**: 기능 시작 전에 `git fetch staymaru && git log main..staymaru/main` 으로 소현님이 같은 걸 하고 있는지 먼저 확인할 것. 이번엔 2시간 차이로 중복 작업이 됐다.
