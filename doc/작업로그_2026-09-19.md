## 2. 코스 로직 변경 (`frontend/src/lib/courseEngine.ts`)

### 2-1. 이동거리 50~60km 문제 해결 — `1c66eda`
- **원인**: 장소 점수가 사실상 카테고리 가중치뿐이라 동점이 많았다. 반경(당일 25km) 안이기만 하면 거리와 상관없이 뽑혀서 반경 양 끝을 왕복했다.
- **수정**: `pickUntil()` 응집 선택. 한 곳씩 뽑되 `score / (1 + (d / clusterKm)^2)`로 뽑는다(d = 이미 고른 장소들의 무게중심까지 거리).
- 기간별 파라미터를 줄였다 (`DURATION_PROFILE`):

| 기간 | 반경 | 컷오프 | 구간상한 | 응집반경 |
|---|---|---|---|---|
| 당일 | 25→15 | 35→25 | 30→15 | 6 |
| 1박2일 | 50→35 | 70→50 | 50→25 | 10 |
| 2박3일 | 80→60 | 110→85 | 75→35 | 15 |

- 테스트: 장소가 흩어진 조건에서 수정 전 36km → 수정 후 15km 미만.

### 2-2. 찜한 장소 보호 — `ed986a4`
- 찜한 장소는 응집 선택의 거리 감점을 받지 않는다. `enforceLegLimit`에서도 제거 대상이 아니다.
- 한계: 찜을 여러 지역에 흩어서 하면 코스가 길어진다. 사용자가 직접 고른 것이라 그대로 둔다.

### 2-3. 날씨별 실내/실외 비율 — `4494ed2`
- 실내 = `hanok, templestay, experience, market, restaurant`. 실외 = 나머지(서원·사찰·둘레길·관광지·축제).
- `rain-likely`(강수확률 ≥ 50%)이면 코스의 **2/3 이상이 실내**, `clear`(< 30%)이면 **2/3 이상이 실외**. `unstable`이면 기존처럼 점수 가중만 한다.
- 구현: 남은 자리를 전부 한쪽으로 채워야 비율이 맞는 시점부터는 그쪽 후보만 본다(`pickUntil` 안).

### 남은 약점 (필요하면 다음에)
- 카테고리 quota가 남은 경우 먼 장소를 강제로 넣을 수 있다. 15km를 넘는 구간만 `enforceLegLimit`이 교체한다.
- 시골 지역은 반경 안 후보가 부족하면 전체 풀로 폴백해서 코스가 길어질 수 있다.
- 2박3일도 한 무게중심으로 모인다. 일자별로 다른 지역을 도는 코스는 안 나온다.
- 화면의 km는 직선거리다. 실제 도로 거리는 약 1.3~1.45배.

### 콘텐츠랩 입력 항목
1. 팀 정보 — 팀명 **쉼마루**(변경 불가, 등록명과 같은지 확인). 최종 팀원 입력(팀원 전원 사전 회원가입 필요)
2. 서비스 정보 — 서비스명 쉼(休)마루 / 유형: 웹 / 지역 특화: **경상북도** (가점 2점, 경북 RTO 특별상 대상)
3. 서비스 URL — https://staymaru-xi.vercel.app
4. 테스트 계정 — **로그인 불필요** 선택 (앱에 로그인 기능 없음. 협업은 방 코드 방식)
5. OpenAPI 활용 정보 — 공공데이터포털 **인증키(인코딩·디코딩)** + 활용 API 목록. 대표 API 1개 운영계정 신청은 선택
6. 기능설명서 — **공식 양식 PPT → PDF로 변환해서 제출**

### 주의
- 심사 측이 제출한 인증키로 **실제 API 호출 건수**를 확인한다. 로컬 DB에 저장해 쓰는 방식은 불리하다(앱은 IndexedDB 24h 캐시 + 실시간 호출 방식).
- 추가 활용신청이 필요한 API(반려동물 `KorPetTourService`, 연관 `TarRlteService`, 데이터랩 `DataLabService`, 무장애 `KorWithService2`)는 **신청·승인된 것만** 기능설명서에 적기. 현재 v4 11번 슬라이드에는 무장애가 들어가 있다 → 미신청이면 삭제.
- 마감 전까지는 접수 페이지에서 수정할 수 있다.

## 5. 로컬 실행
```bash
cd frontend
vercel env pull .env.local --environment=production --yes   # 레포 루트에서: vercel env pull frontend/.env.local ...
npm install
npm run dev   # http://localhost:5173
```
- 개발(development) 환경에는 키가 없다. **반드시 `--environment=production`**으로 받아야 TourAPI·카카오맵이 동작한다.
- `.env.local`은 gitignore 대상이다.
